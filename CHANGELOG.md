# Changelog

## Current state — 2026-10-04

- Renamed the project, application target, test target, module, URLs, bundle identifiers, resources, and supporting documentation to Nextpage.
- Replaced the repository license with the 2026 MIT license for Chinmay Singh; required upstream notices are maintained separately.
- Added `EXPLANATION.md`, a newcomer guide to the app architecture, Swift/AppKit vocabulary, note lifecycle, and development workflow.
- Nextpage is a local-first macOS Markdown journal with folder navigation, editing, Markdown preview, atomic autosave, external-change handling, and security-scoped journal-folder access.
- The app is organized into Business, Controllers, Views, Helpers, Extensions, Resources, and XCTest modules.
- A design document for global and project-specific AI prompt settings is present in `IMPLEMENTATION.md`; that feature is planned, not recorded here as implemented.
