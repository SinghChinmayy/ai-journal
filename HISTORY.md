# History

## Project milestones

- **Nextpage rename:** The project identity was renamed to Nextpage, including its Xcode targets, application module, and user-facing resources.
- **Foundation:** Nextpage was established from the MiaoYan editor codebase under its MIT license.
- **Stage 1:** The local-first Markdown journal workflow was implemented: navigation, note lifecycle, preview, autosave, and recoverable external-change handling.
- **Current direction:** AI-assisted journaling and Git synchronization remain future work; the application makes no AI or sync requests today.

See `CHANGELOG.md` for the current maintained state.
